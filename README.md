설치 없이 휴대폰 브라우저에서 쓰는 운동 모임 앱입니다. Google로 로그인하고 초대 코드로 우리 방에 들어오세요.

- **기록하고 응원하기** — 운동 사진·영상, 좋아요, 댓글, 주별 기록.
- **꾸준함 챙기기** — 주간 목표, 휴식 신청, 내 운동 통계.
- **방장 일 줄이기** — 출석·벌금·정산 기록과 Google Sheets 연동. 실제 송금은 앱 밖에서 해요.

**GitHub가 처음이라면**

GitHub는 앱의 코드를 함께 보고 개선하는 공간이에요. 코드를 몰라도 참여할 수 있습니다. 누구나 읽을 수 있고, 글을 쓰려면 무료 GitHub 계정이 필요해요.

1. 문제가 생기면 **[버그 제보하기](https://github.com/hijaek/undongbang/issues/new?template=bug.yml)**를 누르세요.
2. 어떤 화면에서 무엇을 눌렀는지, 원래 기대한 동작, 휴대폰·브라우저를 적어주세요. 가능하면 개인정보를 가린 스크린샷도 첨부해주세요.
3. 등록된 글을 **Issue(이슈)**라고 불러요. 그 글에서 질문과 수정 진행 상황을 함께 확인합니다. 같은 문제가 있으면 새 글 대신 기존 글에 상황을 덧붙여주세요.

**직접 고치고 싶다면**

오타와 설명 수정도 환영합니다. **Fork**는 코드를 내 계정에 복사하는 것, **Pull request(PR)**는 “이렇게 고쳐봤어요”라고 수정안을 보내는 것이에요. [짧은 기여 안내](CONTRIBUTING.md)를 따라 보내주시면 관리자가 확인합니다. 제보나 PR 등록만으로 앱이 자동으로 바뀌지는 않아요.
